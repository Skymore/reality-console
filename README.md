# Reality Console

Local-first manager for `Xray + REALITY`.

## Current Status

This repository is in planning and early implementation stage.

Files currently prepared:

- [DESIGN.md](./DESIGN.md): UI direction imported from `getdesign`
- [REQUIREMENTS.md](./REQUIREMENTS.md): product scope, MVP, and open questions
- [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md): delivery phases and commit checkpoints

## Product Intent

Reality Console is intended to help a single operator manage a local `Xray + REALITY` setup on macOS without hand-editing JSON for every change.

## Chosen Stack

- `Tauri 2`
- `React`
- `TypeScript`
- `Vite`
- `Tailwind CSS`
- `shadcn/ui`
- `Radix UI`

## Delivery Model

The project is developed in small, explicit phases. Each phase should end in a focused git commit.
